# L3. Обнаружение вмешательства: HC-SR04 + FreeRTOS + MQTT

Реальное железо: Heltec WiFi Kit 32 (ESP32 + OLED), ультразвуковой дальномер HC-SR04,
светодиод на GPIO27. Устройство смотрит на ровную жёсткую поверхность (стена, дверь,
крышка ящика), запоминает расстояние покоя и поднимает тревогу, если его сдвинули,
резко что-то поднесли или закрыли/повернули датчик.

## Подключение

| HC-SR04 / элемент | Heltec |
|---|---|
| Vcc | 5V |
| Gnd | GND |
| Trig | GPIO13 |
| Echo | 1 кОм → GPIO14, и от GPIO14 2,2 кОм → GND (делитель 5 В → 3,4 В) |
| Светодиод | GPIO27 → 1 кОм → анод (длинная нога), катод → GND |
| Испытание связи | встроенная кнопка PRG (GPIO0) |
| Дисплей | встроенный (SDA 4, SCL 15, RST 16, Vext 21) |

## Запуск

1. Скопировать `include/secrets.h.example` в `include/secrets.h` (уже лежит в архиве)
   и вписать имя и пароль Wi-Fi. Сеть только 2,4 ГГц.
2. VS Code + PlatformIO: Open Folder → эта папка → кнопка Upload (→), затем Serial Monitor.
3. Первые ~2 секунды датчик должен смотреть на поверхность неподвижно: идёт калибровка.
4. MQTT Explorer: host `broker.hivemq.com`, port 1883, подписка `utm/si254/vereskul/tamper/#`.

## Логика

Задачи FreeRTOS:

| Задача | Приоритет / ядро | Что делает |
|---|---|---|
| acq | 3 / 1 | семафор от таймера каждые 60 мс → импульс Trig → ширина Echo (прерывание + уведомление задачи) → проверка 2…400 см → медиана 5 → среднее 4 → mutex + очередь |
| app | 2 / 1 | калибровка d_ref, три признака, светодиод, события |
| comm | 1 / 0 | Wi-Fi/MQTT раз в секунду, телеметрия, события из очереди, дисплей |

Признаки вмешательства:

- сдвиг: |d_f − d_ref| ≥ 5 см;
- рывок: |d − d_f| ≥ 15 см, тревога держится 1 с;
- нет эха: 10 пропусков подряд (≈0,6 с), датчик повернули или закрыли.

Испытание потери связи: кнопка PRG или `w` в Serial Monitor (разрыв Wi-Fi на 30 с),
`m` (разрыв только MQTT). События за это время копятся в очереди и уходят после восстановления.

Topics: `.../telemetry` (раз в секунду), `.../event` (CALIBRATED, TAMPER_ON/OFF, JUMP),
`.../status` (online/offline, retained + Last Will).
